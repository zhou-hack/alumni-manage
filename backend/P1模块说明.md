## 一、P1 新增模块（backend/ 下独立文件夹）

## 三、公共底座扩展（backend/common）

- **ErrorCode**：+TAG_DUPLICATED(409)、SCOPE_REQUIRED(400)、HANDOVER_INVALID(409)、EXPORT_LIMIT_EXCEEDED(429)
- **SecurityConfig**：P1 全部路径规则（counselors 仅 SCHOOL_ADMIN；tags 读写分权；search/notifications/subscriptions 登录；field-permissions GET 校级+系统/PUT 系统；admin/users 四动作仅系统；audit-logs 仅系统）
- **JwtAuthFilter + SuspendedUserStore（新增）**：停权账号 Redis 标记（auth:suspended:{userId}），已签发 Token 即刻作废（401/403），配合 refresh_token 全量吊销
- **PinyinUtils（新增，pinyin4j）**：全拼 + 首字母预生成（规范决策 P1-Q3：MySQL 拼音列，不引入 ES）

## 五、关键设计决策

1. **导员账号**：users.alumni_base_id 有 NOT NULL FK，创建导员时配套生成 alumni_base 桩行（student_id="T"+手机号 工号式唯一，grad_year=0）。
2. **无导员覆盖兜底**：提交/重提统一执行覆盖检查（同学院 + 届别∪专业∪学号任一命中 + 导员 active），未命中直接进院系初审，流程不卡死。
3. **跨模块协作**：沿用「共享库直写」JdbcTemplate 惯例（reviews/announcement 直写 notifications；各模块直写 audit_logs），模块间零 jar 依赖。
4. **交接跨学院限制**（P1-Q6）：counselor/college_admin 比较 alumni_base.college 文本，不同 → 409 HANDOVER_INVALID「仅限本院」。
5. **审计导出**：规范「异步任务」简化为同步流式 xlsx（已在类注释注明）；限流内存滑动窗口。
6. **外部消息**：SMS 复用 mock 通道、邮件按「失败仅记日志」——统一按订阅过滤后 log 模拟发送。
7. **实体重名**：跨模块同表实体按 `{module}{Class}` 命名（counselorsUser/counselorsAlumniBase/adminAuditLog）。
