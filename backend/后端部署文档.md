# 校友管理平台 · 后端部署文档

> 后端形态：Spring Boot 3.5 模块化单体（单 JVM / 单端口 / 单部署单元 `alumni-platform.jar`）
> 唯一启动入口：`backend/app` 模块 `com.alumni.app.PlatformApplication`
> 接口基址：`http://<host>:8080/api/v1`，统一响应信封 `{code, message, data, request_id, timestamp}`

---

| 组件 | 版本要求 | 说明 |

## 二、数据库账户

| 账户 | 密码 | 用途 | 权限 |
|---|---|---|---|
| `root` | `Zjb@070929` | 本机 MySQL 管理员（仅运维使用，勿配置进应用） | 全部 |
| `alumni` | `alumni_dev@0123` | **应用专用账户**（host: `localhost` + `%`） | `alumni_platform.*` 全部 |

- 数据库名：`alumni_platform`（utf8mb4 / utf8mb4_unicode_ci / InnoDB）
- 建账户 SQL（root 登录执行）：

```sql
CREATE DATABASE IF NOT EXISTS alumni_platform CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'alumni'@'localhost' IDENTIFIED BY 'alumni_dev@0123';
CREATE USER IF NOT EXISTS 'alumni'@'%'         IDENTIFIED BY 'alumni_dev@0123';
GRANT ALL PRIVILEGES ON alumni_platform.* TO 'alumni'@'localhost';
GRANT ALL PRIVILEGES ON alumni_platform.* TO 'alumni'@'%';
FLUSH PRIVILEGES;
-- 忘记密码时重置：
-- ALTER USER 'alumni'@'localhost' IDENTIFIED BY 'alumni_dev@0123';
```

- **建表不需要手工执行 SQL**：应用启动时由 Flyway 自动迁移
  （`backend/app/src/main/resources/db/platform/` 下 V1/V2/V3 脚本，幂等，空库自动建全表）。
  `backend/db/schema.sql` 为全量结构参考文档，仅供查阅。

## 三、配置项（环境变量）

全部配置有默认值，生产/联调通过环境变量覆盖（`backend/app/src/main/resources/application.yml`）：

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `DB_URL` | `jdbc:mysql://127.0.0.1:3306/alumni_platform?...` | 数据源 |
| `DB_USER` | `root` | **部署时设为 `alumni`** |
| `DB_PASSWORD` | `123456` | **部署时设为 `alumni_dev@0123`** |
| `REDIS_HOST` / `REDIS_PORT` | `127.0.0.1` / `6379` | Redis |
| `JWT_SECRET` | 开发默认值 | **生产必须覆盖**为独立随机密钥 |
| `STORAGE_ROOT` | `./storage` | 附件落盘根目录（勿提交 git） |

## 四、构建与启动

```powershell
# 1. 构建（在 backend/ 目录，跳过测试）
mvn -DskipTests package
# 产物：backend/app/target/alumni-platform.jar

# 2. 启动 Redis（本机）
.\redis\redis-server.exe --port 6379 --bind 127.0.0.1

# 3. 启动后端（在 backend/app/ 目录）
$env:DB_USER='alumni'; $env:DB_PASSWORD='alumni_dev@0123'
java -jar target\alumni-platform.jar
```

启动成功标志：日志出现 `Started PlatformApplication` + `种子数据已初始化`（仅空库首次）。

## 五、前端联调

前端为 npm workspace（`frontend/`，portal 门户 5173 + admin 后台 5174）：

```powershell
cd frontend
npm install
npm run dev    # concurrently 同时起 portal(5173) / admin(5174)
```

- 两端均通过 vite proxy 将 `/api` 转发到 `http://localhost:8080`（可用 `VITE_PROXY_TARGET` 覆盖）
- `VITE_USE_MOCK=false`（默认）即走真实后端；不要设为 `true`

## 八、运维注意

1. **生产必改**：`JWT_SECRET`、`DB_PASSWORD`；短信 `app.sms.mock` 置 `false` 并接入真实短信服务商（替换 `SmsCodeService#send`）。
2. Redis 不可用时：停权拦截自动降级放行，但**短信验证码 / 激活核验 / 密码重置不可用**（硬依赖）。
3. 附件/导入文件落盘 `STORAGE_ROOT`（默认 `./storage`），已 gitignore，部署时需持久化该目录。
4. 停权即时生效依赖 Redis 键 `auth:suspended:{userId}`；refresh_token 有效期 7 天，access_token 2 小时。
