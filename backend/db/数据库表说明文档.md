## 全局约定（适用于所有表）

- 主键统一 `id BIGINT UNSIGNED AUTO_INCREMENT`
- 时间统一 `TIMESTAMP(6)`，**UTC 存储**（连接串 `connectionTimeZone=UTC&forceConnectionTimeZoneToSession=true`）
- 业务表统一 FK 到 `users.id`；**多态关联不设外键**：附件 `(biz_type, ref_id)`、审核 `(biz_type, biz_id)`，引用完整性由应用层保证
- 外键默认 `RESTRICT`；删除一律逻辑化（如 `archives.status=deleted`）或审计化（删前留痕），保审计链路
- `created_at` 默认 `CURRENT_TIMESTAMP(6)`；`updated_at` 额外 `ON UPDATE CURRENT_TIMESTAMP(6)`

## 表关系总览

```
alumni_base 1 ──── 1 users（uk_users_alumni_base_id）
                      │
                      ├── 1:N refresh_tokens（登录续期）
                      ├── 1:N archives（归属校友）
                      ├── 1:N honors（荣誉申报人）
                      ├── 1:N attachments（uploader_id 上传人）
                      ├── 1:N consents（授权人）
                      ├── 1:N drafts（草稿）
                      ├── 1:N import_tasks（uploader_id 导入人）
                      ├── N:1 showcase（published_by 发布管理员）
                      └── N:1 reviews / review_logs（reviewer_id / submitter_id / operator_id）

archives 1 ──── N honors（archive_id 可空关联）
        1 ──── N consents（授权的档案）
        1 ──── 1 showcase（行存在=上架中，uk_showcase_archive）

attachments 1 ──── N showcase（cover_attachment_id 封面快照）
dicts 自关联（parent_id：major → college）
reviews 1 ──── N review_logs
import_tasks 1 ──── N import_errors

※ archives / honors 的审核走 reviews 通道：reviews.biz_type + biz_id 多态指向，不设外键
※ consents 撤回（DELETE）→ 应用层联动删除 showcase 行（自动下架）
```

## 1. `users` — 平台账号

**功能**：所有角色的登录账号（student / alumni / counselor / college_admin / school_admin / system_admin）。登录鉴权（密码/短信）、JWT 签发主体。

**字段列表**

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 内部主键，跨表关联统一用它 |
| uuid | VARCHAR(36) | NOT NULL, UNIQUE | — | 对外对接 UUID（v4，创建时生成，不可变；内部关联仍用 id） |
| alumni_base_id | BIGINT UNSIGNED | NOT NULL, UNIQUE, FK→alumni_base.id | — | 关联校友库记录（1:1，一个底册只能开一个账号） |
| student_id | VARCHAR(32) | NOT NULL, UNIQUE | — | 学号 |
| phone | VARCHAR(16) | NOT NULL, UNIQUE | — | 登录手机号（激活时可换绑） |
| nickname | VARCHAR(64) | NOT NULL | — | 昵称 |
| role | VARCHAR(32) | NOT NULL | — | student/alumni/counselor/college_admin/school_admin/system_admin |
| password_hash | VARCHAR(100) | NOT NULL | — | BCrypt(SHA-256(原文)) 双层散列（前端先 SHA-256，服务端再 BCrypt） |
| created_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) | 创建时间 |
| updated_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) ON UPDATE | 更新时间 |

**主键/外键/索引**

- 主键：`id`
- 外键：`fk_users_alumni_base (alumni_base_id) → alumni_base(id)`
- 唯一索引：`uk_users_uuid`、`uk_users_student_id`、`uk_users_phone`、`uk_users_alumni_base_id`
- 普通索引：`idx_users_role`（按角色筛选）

**与其他表的关系**：被 refresh_tokens / archives / honors / attachments / consents / drafts / import_tasks / reviews / review_logs / attachment_audit_log / showcase 外键引用，是全平台的账号中枢。

## 2. `alumni_base` — 校友库

**功能**：校友"底册"（学号、姓名、身份证、学院、专业、毕业年份）。两个用途：① 激活三要素核验的数据源（student_id + real_name + id_card 比对）；② 批量导入（Imports）的目标表。

**字段列表**

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键 |
| student_id | VARCHAR(32) | NOT NULL, UNIQUE | — | 学号（导入幂等与查重的依据） |
| real_name | VARCHAR(64) | NOT NULL | — | 真实姓名 |
| id_card | VARCHAR(32) | NOT NULL | — | 身份证号（明文存储，仅用于激活核验；生产建议 TDE 磁盘加密+库级权限隔离） |
| phone | VARCHAR(16) | NOT NULL | — | 校友库登记手机号（非登录手机号） |
| college | VARCHAR(64) | NULL 允许 | NULL | 学院（**文本**，对齐 dicts 的 college.label） |
| major | VARCHAR(64) | NULL 允许 | NULL | 专业 |
| grad_year | INT | NOT NULL | — | 毕业年份 |
| created_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) | 创建时间 |

**主键/外键/索引**

- 主键：`id`
- 外键：无（被 users 引用）
- 唯一索引：`uk_alumni_base_student_id`（同号不可重复导入）
- 普通索引：`idx_alumni_base_college_year (college, grad_year)`（学院+年份筛选，Stats 排行用）、`idx_alumni_base_real_name`（按姓名检索）

**与其他表的关系**：`users.alumni_base_id` 1:1 指向本表；Stats 学院排行通过 users JOIN 本表取 college 文本聚合。⚠ college/major 为文本字段，**必须与 dicts 对齐**，否则统计排行碎片化。

## 3. `refresh_tokens` — 刷新令牌

**功能**：refresh_token 的服务端登记（哈希存储，不落明文）。access_token 过期后凭它换新（轮换制：旧 token 用后作废）。

**字段列表**

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键 |
| user_id | BIGINT UNSIGNED | NOT NULL, FK→users.id | — | 归属用户 |
| token_hash | VARCHAR(64) | NOT NULL, UNIQUE | — | SHA-256(refresh_token)，不存明文 |
| expires_at | TIMESTAMP(6) | NOT NULL | — | 过期时间 |
| revoked | TINYINT(1) | NOT NULL | 0 | 是否已作废（轮换/登出时置 1） |
| created_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) | 签发时间 |

**主键/外键/索引**

- 主键：`id`
- 外键：`fk_refresh_tokens_user (user_id) → users(id)`
- 唯一索引：`uk_refresh_tokens_hash`
- 普通索引：`idx_refresh_tokens_user`

**与其他表的关系**：N:1 users。

## 4. `dicts` — 基础字典

**功能**：全平台统一的"下拉选项库"。目前承载 college（学院）/ major（专业，parent_id 挂在学院下）/ honor_category（荣誉分类）三类；grad_year 为虚拟类型（接口动态生成，不存表）。读取开放给所有登录角色（`GET /dicts/{type}`），写入仅 school_admin（`POST /dicts/{type}`）。

**字段列表**

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键 |
| type | VARCHAR(32) | NOT NULL | — | 选项类别：college/major/grad_year/honor_category，随业务扩充 |
| parent_id | BIGINT UNSIGNED | NULL 允许, FK→dicts.id | NULL | 父级字典项（major 归属 college；其余类型为 NULL） |
| label | VARCHAR(64) | NOT NULL | — | 展示文本（如"计算机学院"） |
| value | VARCHAR(64) | NOT NULL | — | 存储值/代码（如"CS"）；业务表存 value，界面显示 label |
| sort | INT | NOT NULL | 0 | 排序序号 |
| created_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) | 创建时间 |
| updated_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) ON UPDATE | 更新时间 |

**主键/外键/索引**

- 主键：`id`
- 外键：`fk_dicts_parent (parent_id) → dicts(id)`（自关联，构成树形）
- 唯一索引：`uk_dicts_type_value (type, value)`（同类目下 value 不重复）
- 普通索引：`idx_dicts_type_sort`（按类别+序号取出）、`idx_dicts_parent`

**与其他表的关系**：无外键被引用——alumni_base.college/major（文本对齐）、honors.category（对齐 honor_category）均为**应用层口径约束**。被引用项禁止删除（409 RESOURCE_REFERENCED）。

## 5. `archives` — 校友档案

**功能**：校友提交的档案条目（获奖成果/经历/证书……）。生命周期：draft → 提交 → pending_first → 学院初审 → pending_second → 校级复核 → approved / rejected；删除走 deleting → deleted（审核化软删除）。

**字段列表**

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键 |
| user_id | BIGINT UNSIGNED | NOT NULL, FK→users.id | — | 归属校友 |
| title | VARCHAR(128) | NOT NULL | — | 标题 |
| category | VARCHAR(32) | NOT NULL | — | 类别：award/experience/certificate……自由扩展 |
| content | TEXT | NULL 允许 | NULL | 正文 |
| remark | VARCHAR(255) | NULL 允许 | NULL | 备注 |
| status | VARCHAR(16) | NOT NULL | 'draft' | draft/pending_first/pending_second/approved/rejected/deleting/deleted |
| version | INT | NOT NULL | 1 | 乐观锁版本：驳回重提 version+1，版本历史见 review_logs |
| reject_reason | VARCHAR(500) | NULL 允许 | NULL | 最近一次驳回原因（前端回显用） |
| prev_status | VARCHAR(16) | NULL 允许 | NULL | delete-request 前的原状态（archive_delete 驳回时恢复用） |
| created_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) | 创建时间 |
| updated_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) ON UPDATE | 更新时间 |

**主键/外键/索引**

- 主键：`id`
- 外键：`fk_archives_user (user_id) → users(id)`
- 普通索引：`idx_archives_user`、`idx_archives_status_cat (status, category)`（待办列表按状态+类别筛）、`idx_archives_created`

**与其他表的关系**：被 honors.archive_id（可空）、consents.archive_id、showcase.archive_id（唯一，1:1 上架）引用；审核走 reviews（biz_type='archive'/'archive_delete'，biz_id 多态指向本表 id，不设外键）。上架条件：status=approved **且** consent 有效。

## 6. `honors` — 校友荣誉

**功能**：独立结构化的荣誉/奖项登记（与 archives 的 award 类别互补但独立）。统计模块荣誉分布的**唯一数据源**。防重复规则：同 user + 同 title + 同 awarded_at 且 status ∈ (pending_first, pending_second, approved) → 409 INVALID_STATE。

**字段列表**

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键 |
| user_id | BIGINT UNSIGNED | NOT NULL, FK→users.id | — | 申报校友 |
| archive_id | BIGINT UNSIGNED | NULL 允许, FK→archives.id | NULL | 可关联档案（非 Archive 的 category 语义） |
| title | VARCHAR(128) | NOT NULL | — | 荣誉名称 |
| category | VARCHAR(32) | NOT NULL | — | 分类：scholarship/competition……对齐 dicts 的 honor_category |
| level | VARCHAR(32) | NOT NULL | — | 级别：national/provincial/school…… |
| awarded_at | DATE | NOT NULL | — | 获奖日期（纯日期 YYYY-MM-DD） |
| status | VARCHAR(16) | NOT NULL | 'pending_first' | pending_first/pending_second/approved/rejected（走 Reviews 通道） |
| created_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) | 创建时间 |
| updated_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) ON UPDATE | 更新时间 |

**主键/外键/索引**

- 主键：`id`
- 外键：`fk_honors_user (user_id) → users(id)`、`fk_honors_archive (archive_id) → archives(id)`
- 普通索引：`idx_honors_user`、`idx_honors_cat_level (category, level)`（Stats 荣誉分布 GROUP BY 用）、`idx_honors_status`、`idx_honors_awarded`

**与其他表的关系**：审核走 reviews（biz_type='honor'，多态）；统计接口（荣誉分布、总数）直接聚合本表。

## 7. `attachments` — 附件

**字段列表**

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键 |
| biz_type | VARCHAR(32) | NOT NULL | — | 业务目录隔离：archive/honor/avatar/activate…… |
| ref_id | BIGINT UNSIGNED | NULL 允许 | NULL | 业务记录 ID（多态，不设外键）；NULL=未引用（孤儿清理依据） |
| status | VARCHAR(16) | NOT NULL | 'unreferenced' | unreferenced / referenced |
| url | VARCHAR(255) | NOT NULL | — | 相对路径 /files/{biz_type}/yyyy/MM/xx |
| name | VARCHAR(128) | NOT NULL | — | 原始文件名 |
| size | BIGINT | NOT NULL | — | 字节数（图片为压缩后） |
| mime | VARCHAR(64) | NOT NULL | — | MIME 类型 |
| uploader_id | BIGINT UNSIGNED | NOT NULL, FK→users.id | — | 上传人 |
| remark | VARCHAR(255) | NULL 允许 | NULL | 备注 |
| created_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) | 上传时间 |
| referenced_at | TIMESTAMP(6) | NULL 允许 | NULL | 被引用时间 |

**主键/外键/索引**

- 主键：`id`
- 外键：`fk_attachments_uploader (uploader_id) → users(id)`
- 普通索引：`idx_attachments_biz_ref (biz_type, ref_id)`（按业务记录取附件）、`idx_attachments_orphan (status, created_at)`（孤儿定时清理扫描）

**与其他表的关系**：被 showcase.cover_attachment_id 引用；archives / honors 通过 payload 里的 attachment_ids 多态引用本表（应用层保证）。

## 9. `reviews` — 审核记录

**功能**：全业务共用的审核通道（独立资源）。当前承载四类：archive（档案）/ honor（荣誉）/ archive_delete（档案删除申请）/ activate_manual（人工激活）。两级审核：学院管理员看 first（初审），校级管理员看 second（复核）；activate_manual 仅 first 单级。

**字段列表**

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键 |
| biz_type | VARCHAR(32) | NOT NULL | — | 业务类型：archive/honor/archive_delete/activate_manual |
| biz_id | BIGINT UNSIGNED | NULL 允许 | NULL | 业务记录 ID（**多态，不设外键**，应用层保证） |
| submitter_id | BIGINT UNSIGNED | NULL 允许, FK→users.id | NULL | 业务提交人（审核日志对本人可见用） |
| stage | VARCHAR(16) | NOT NULL | 'first' | first / second |
| status | VARCHAR(16) | NOT NULL | 'pending' | pending / approved / rejected |
| reviewer_id | BIGINT UNSIGNED | NULL 允许, FK→users.id | NULL | 最近一次操作的审核人 |
| reason | VARCHAR(500) | NULL 允许 | NULL | 驳回原因（reject 必填） |
| created_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) | 创建时间 |
| updated_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) ON UPDATE | 更新时间 |

**主键/外键/索引**

- 主键：`id`
- 外键：`fk_reviews_reviewer (reviewer_id) → users(id)`、`fk_reviews_submitter (submitter_id) → users(id)`
- 普通索引：`idx_reviews_todo (biz_type, stage, status)`（待办列表核心索引）、`idx_reviews_biz (biz_type, biz_id)`（按业务记录查审核）、`idx_reviews_submitter`

**与其他表的关系**：biz_id 多态指向 archives / honors 等业务表（不设外键）；1:N review_logs。

## 10. `review_logs` — 审核日志

**功能**：审核动作留痕（谁/何时/动作/原因），提交人与审核角色可见；版本历史（驳回重提 version+1）也依赖本表。

## 11. `showcase` — 上架记录

**功能**：大屏（Screen）公开墙的上架登记。**行存在=上架中，下架=删行**；consent 撤回时应用层联动删行（自动下架）。上架前置条件：archives.status=approved 且 consent 有效。

**字段列表**

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键 |
| archive_id | BIGINT UNSIGNED | NOT NULL, UNIQUE, FK→archives.id | — | 上架的档案（一档案最多一条上架记录） |
| cover_attachment_id | BIGINT UNSIGNED | NULL 允许, FK→attachments.id | NULL | 发布时快照封面（取首个已引用图片附件） |
| published_by | BIGINT UNSIGNED | NOT NULL, FK→users.id | — | 发布人（school_admin） |
| published_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) | 发布时间 |

**主键/外键/索引**

- 主键：`id`
- 外键：`fk_showcase_archive → archives(id)`、`fk_showcase_cover → attachments(id)`、`fk_showcase_publisher → users(id)`
- 唯一索引：`uk_showcase_archive`（防重复上架）

**与其他表的关系**：N:1 archives（唯一）/ attachments / users；被 consents 撤回联动删除（应用层）。

## 12. `consents` — 隐私授权

**功能**：校友对某条档案的公开展示授权。scope=screen（大屏）现为唯一生效范围，site（站点）预留。撤回=删行，并联动删除 showcase 上架记录。

**字段列表**

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键 |
| user_id | BIGINT UNSIGNED | NOT NULL, FK→users.id | — | 授权人（必须与 archives.user_id 一致，归属校验） |
| archive_id | BIGINT UNSIGNED | NOT NULL, FK→archives.id | — | 被授权的档案 |
| scope | VARCHAR(16) | NOT NULL | — | screen（大屏）/ site（站点，预留） |
| created_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) | 授权时间 |

**主键/外键/索引**

- 主键：`id`
- 外键：`fk_consents_user → users(id)`、`fk_consents_archive → archives(id)`
- 唯一索引：`uk_consents_archive_scope (archive_id, scope)`（同一档案同一范围只允许一条授权，并发授权冲突由它兜底返回 409）
- 普通索引：`idx_consents_user`

**与其他表的关系**：N:1 archives / users；撤回时应用级联删除 showcase 行。

## 13. `import_tasks` — 导入任务

**功能**：第十一章批量导入的任务头。CSV 上传受理即建行，异步逐行校验入库；**坏行不阻断好行**，合法行入 alumni_base，坏行记 import_errors。

## 15. `drafts` — 草稿

**功能**：第十二章服务端草稿兜底（浏览器 localStorage 之外的第二层）。用户每类业务（biz_type）只保留一份草稿；正式提交成功后删除对应行。保存采用**乐观锁**：提交版本=服务端版本才落盘并 version+1。

**字段列表**

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键 |
| user_id | BIGINT UNSIGNED | NOT NULL, FK→users.id | — | 归属用户 |
| biz_type | VARCHAR(32) | NOT NULL | — | 草稿业务：archive/…… |
| version | INT | NOT NULL | 1 | 乐观锁：提交版本=服务端版本才保存并 +1 |
| payload | JSON | NOT NULL | — | 草稿内容（标题/正文/attachment_ids 等） |
| created_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) | 创建时间 |
| updated_at | TIMESTAMP(6) | NOT NULL | CURRENT_TIMESTAMP(6) ON UPDATE | 更新时间 |

**主键/外键/索引**

- 主键：`id`
- 外键：`fk_drafts_user (user_id) → users(id)`
- 唯一索引：`uk_drafts_user_biz (user_id, biz_type)`（一人一业务一份草稿）

**与其他表的关系**：N:1 users；payload 中的 attachment_ids 关联 attachments（应用层）。

## 16. `flyway_schema_history` — Flyway 迁移历史（框架表）

**功能**：Flyway 框架自动维护的迁移版本表，记录已执行过的 DDL 迁移脚本（version / description / checksum / success）。**禁止手工修改**；重名/改历史脚本会导致校验失败（应用启动时 `DbValidate`）。

**关键字段**（框架管理）：`installed_rank`（PK）、`version`（版本号，如 1、2）、`description`、`type`、`script`、`checksum`、`installed_by`、`installed_on`、`execution_time`、`success`。

**与其他表的关系**：无。仅记录迁移元数据。

> 注意：本库当前 schema 版本 2 由迁移脚本写入（V1 建 alumni_base 前置表 + V2 等），与 backend/db/schema.sql（全量基准）并行维护——改表流程 = 改 schema.sql + 增量幂等迁移脚本。
